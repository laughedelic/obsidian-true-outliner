3. The cross-regime case

A heading section dragged into a list does not stay a heading — the destination's encoding decides, and the whole subtree re-encodes with it. An indicator that draws the run's current mark promises something the release will not deliver; one that draws the mark the run will have is the only version that stays true across this case.
